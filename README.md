## Цель работы

Научиться считывать структурированные данные из текстового файла, хранить записи в векторе структур, выполнять поиск по заданному признаку и вычислять статистические показатели.

## Задача

Файл содержит сведения об автомобилях: марка, год выпуска, фамилия владельца и номер. Выведите сведения об автомобилях задаваемой марки и определите их средний возраст. Среди всех автомобилей найдите самую старую машину.

## Используемые средства

- `<fstream>` — открытие и построчное чтение файла `ifstream`, `getline()`;
- `<sstream>` — разбор строки с годом выпуска и проверка, что она содержит целое число;
- `<string>` — хранение марки, фамилии владельца и номера;
- `<vector>` — список всех прочитанных автомобилей;
- `<iomanip>` — вывод среднего возраста с точностью до двух знаков (`fixed`, `setprecision(2)`);
- `struct Car` — запись из четырёх полей: `brand`, `year`, `owner`, `plateNumber`.

## Входные данные

### Файл `text.txt`

Файл должен находиться в рабочей директории запуска программы. Каждая строка содержит четыре поля, разделённые точкой с запятой:

```
марка;год выпуска;фамилия владельца;номер
```

Пример содержимого:

```text
Toyota;2015;Ivanov;A123BC
Lada;2020;Petrov;X789YZ
Toyota;2010;Sidorov;E456TN
BMW;2018;Smirnov;O001OO
```

Строки, в которых количество полей отличается от четырёх или год выпуска не является целым числом, пропускаются.

### Ввод с клавиатуры

Одна строка — марка автомобиля, сведения о которой нужно вывести. Строка читается целиком через `getline(cin, brandCar)`, поэтому марка может содержать пробелы.

## Выходные данные

- Весь список автомобилей из файла в формате `Марка  Владелец  Номер  Год` (поля разделены табуляцией).
- Год выпуска самой старой машины: `The oldest car from year <год>`.
- Сведения об автомобилях заданной марки в том же формате, что и общий список.
- Средний возраст найденных автомобилей: `Average age: <значение> years`.
- Если автомобили такой марки отсутствуют, выводится `No cars of this brand`.
- Если файл `text.txt` не найден, выводится `INVALID: file not found` и программа завершается с кодом `1`.

Возраст автомобиля вычисляется как `2026 - год выпуска`.

## Алгоритм работы

1. Открыть файл `text.txt`; при неудаче вывести сообщение об ошибке и завершить работу.
2. Считывать файл по строкам до конца.
3. Разбить каждую строку на поля по разделителю `;` с помощью `splitFields()`.
4. Если полей четыре и год выпуска проходит проверку `readInt()`, сохранить запись в `vector<Car>` и вывести её на экран.
5. Найти минимальный год выпуска среди всех прочитанных автомобилей — это год самой старой машины.
6. Запросить у пользователя марку автомобиля.
7. Просмотреть все записи и вывести те, у которых марка совпала с введённой; одновременно посчитать их количество и суммарный возраст.
8. Если совпадений нет, вывести `No cars of this brand`, иначе вывести средний возраст как `сумма возраста / количество` с точностью до двух знаков.

## Пример работы

Содержимое `text.txt` — как в разделе «Входные данные». Ввод пользователя: `Toyota`.

```text
All the cars in the garage
Toyota  Ivanov   A123BC  2015
Lada    Petrov   X789YZ  2020
Toyota  Sidorov  E456TN  2010
BMW     Smirnov  O001OO  2018

The oldest car from year 2010

Enter the car brand you are interested in
Toyota  Ivanov   A123BC  2015
Toyota  Sidorov  E456TN  2010
Average age: 13.50 years
```

Для Toyota возраст равен `2026 - 2015 = 11` и `2026 - 2010 = 16`, среднее значение `(11 + 16) / 2 = 13.50`.

## Сборка и запуск

```bash
g++ -std=c++17 -Wall -Wextra -o build/main main.cpp
./build/main
```

Перед запуском убедитесь, что файл `text.txt` находится в той же директории, из которой запускается программа.

## Особенности текущей реализации

- Для самой старой машины выводится только год выпуска, а не полный комплект сведений.
- Текущий год задан константой `2026` в выражении расчёта возраста, а не определяется системным временем.
- Марка сравнивается без учёта регистра: `toyota` и `Toyota` считаются разными марками.
- Если в файле нет ни одной корректной записи, обращение к `carsGarage[0]` при поиске самой старой машины приведёт к неопределённому поведению.
